# V5 Design Direction

A full visual reset away from traditional boxed Bootstrap ecommerce.

- Edge-to-edge editorial commerce layout
- Compact glass navigation instead of a tall stacked header
- Full-bleed image-led hero with an embedded shopping search
- Horizontal category rail and product stories rather than repeated cards
- Strong whitespace, sharp type hierarchy and fewer rounded containers
- Persona journeys are integrated into the content instead of shown as corporate feature boxes
- Shop uses an editorial catalogue layout with sticky controls and cleaner product tiles
- Compact, asymmetric footer with minimal vertical height
